# Flutter RAG Chat App 

A clean, responsive cross-platform Flutter application designed as an interactive user interface for Retrieval-Augmented Generation (RAG) pipelines and LLM workflows.

## Features 

* **Interactive Chat Interface:** Real-time message streaming layout handling user queries and AI responses seamlessly.
* **State Management:** Built with clean reactive state architecture to manage conversation history and loading states.
* **Cross-Platform Ready:** Configured to run smoothly on Android, iOS, Web, Windows, and macOS.
* **Custom API Integration:** Built to connect cleanly with custom backend LLM services and vector databases.
